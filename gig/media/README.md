# Media directory

Put operator-owned source and transcoded clips under this directory. Media files are excluded from Git because they are large, show-specific, and may be copyrighted.

The historical `gig/show.json` records the filenames used by the original show. Those files are not included; replace its clip paths with your own media or use the tools documented in [`../../docs/original/MEDIA.md`](../../docs/original/MEDIA.md).

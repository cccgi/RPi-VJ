**Commands to run on the production Raspberry Pi and workstation:**

1. **Capture baseline state on the running Pi:**
   ```bash
   bash scripts/appliance/capture-baseline.sh /var/tmp/baseline-$(date +%Y%m%d_%H%M%S)
   ```
2. **Shutdown Pi and image the production microSD card on workstation:**
   ```bash
   sudo systemctl poweroff
   # On workstation:
   sudo dd if=/dev/<sd_device> of=rpi-vj-baseline-$(date +%Y%m%d).img bs=4M status=progress conv=fsync
   sha256sum rpi-vj-baseline-*.img > rpi-vj-baseline-$(date +%Y%m%d).img.sha256
   ```
3. **Restore image to a spare microSD card:**
   ```bash
   sudo dd if=rpi-vj-baseline-*.img of=/dev/<spare_sd_device> bs=4M status=progress conv=fsync
   sync
   ```
4. **Boot test the spare card:**
   Insert the restored spare card into the Pi, connect HDMI, power on, and confirm clean boot into multi-user target.

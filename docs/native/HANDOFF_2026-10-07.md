## What changed architecturally

The appliance runtime pivoted away from Chromium/Chrome. The deployed Pi
runtime is a Rust application using SDL2/KMS/DRM + OpenGL ES, libmpv for local
video playback, ALSA audio, and a native Stream Deck controller. Edge/Chrome
and Playwright exist only on the desktop for Shadertoy acquisition; neither is
part of the Pi renderer.

Core source:

```text
engine/src/main.rs                 native CLI
engine/src/native/mod.rs           SDL/KMS lifecycle, live loop, diagnostics
engine/src/native/render.rs        OpenGL ES renderer; lazy GPU shader compilation
engine/src/native/mpv.rs           libmpv clip path
engine/src/audio.rs                analysis pipeline
engine/src/control.rs              state, crate/delete actions
engine/src/controller.rs           Stream Deck display/commands
engine/src/bin/controller.rs       controller executable
engine/src/ipc.rs                  Unix-socket transport
engine/src/show.rs                 JSON show manifest
```

The renderer was changed to load/prepare sources at startup and compile GPU
programs when selected. This was necessary because eager compilation of the
full library prevented reliable startup.

## Stream Deck pages

Generator: `engine/tools/build_shader_review_show.py`.

It groups source shaders into four heuristic clusters:

1. fractal / Julia / Mandelbrot / raymarch / distance field
2. noise / plasma / cloud / fire / water / liquid / smoke
3. kaleidoscope / symmetry / tunnel / vortex / spiral / warp
4. other

Key mapping is zero-based in the manifest, physical-key numbering in
parentheses:

| Manifest keys | Physical keys | action |
|---:|---:|---|
| 0–23 | 1–24 | shader triggers, large original-library `#NNN` labels |
| 24 | 25 | previous page |
| 25 | 26 | next page |
| 26–29 | 27–30 | crate 1–4 assignment |
| 30 | 31 | delete current shader |
| 31 | 32 | blackout/page status |

`engine/src/control.rs` contains persisted `shader_crates` and
`deleted_shaders`; `engine/src/controller.rs` draws enlarged `#NNN` labels.

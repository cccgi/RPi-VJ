# Task Specification: TB-07 — CSV metrics logging on both machines

## 1. Goal
Turn TB-06's stdout fps line into a structured CSV log with the fields Gate B / ADR-100 actually need to compare
backends, and produce one run's worth of data from both the 3090 PC and the M2 Pro Mac.

## 2. Target Files
* **New**: `vj/tools/gpu-spike/src/metrics.rs`
* **Modify**: `vj/tools/gpu-spike/src/main.rs`
* **New (output, not source)**: `vj/tools/gpu-spike/gpu-spike-results-pc.csv` and
  `vj/tools/gpu-spike/gpu-spike-results-mac.csv` — generated by running the program, not hand-written.

## 3. Requirements & Constraints
1. `metrics.rs`: a `MetricsLogger` that opens a CSV file at startup (path from `std::env::args()` — accept an
   optional first CLI arg as the output path, default to `gpu-spike-results.csv` if none given) and writes a
   header row: `frame,wall_time_s,frame_ms,fps,adapter_name,backend`. Every frame, append one row (adapter_name
   / backend are constant per run — repeat them each row, this keeps the CSV self-describing without a second
   file).
2. Wire it into the render loop from TB-06: call `logger.record(frame_index, elapsed_s, frame_ms)` each frame
   instead of (or in addition to — your choice) the `println!` from TB-06.
3. Flush the file on window close (the `WindowEvent::CloseRequested` handler) so the CSV isn't truncated.
4. No CPU/GPU temperature or memory reading in this task — `wgpu` doesn't expose that portably and adding
   `nvml-wrapper` (NVIDIA-only) or IOKit calls (macOS-only) is out of scope for this spike; note in your report
   that this field is deferred, don't silently drop it from the roadmap's exit criteria — flag it for the
   architect.

## 4. Acceptance Criteria & Observable
On the 3090 PC: run `cargo run -p gpu-spike --release -- gpu-spike-results-pc.csv` for at least 30 seconds, then
close the window. The CSV must exist, be non-empty, have the correct header, and every row's `adapter_name`
must match what TB-02 printed.
On the M2 Pro Mac: same command with `gpu-spike-results-mac.csv`, same duration.
Paste the first 3 and last 3 rows of each CSV into your report.

## 5. Report
Append to `tasks/RESULTS-TRACKB.md`: first/last 3 rows of both CSVs, row counts, rough average fps on each
machine, the flagged temperature/memory gap, anything that surprised you. ≤10 lines (the CSV excerpt doesn't
count against the line limit — keep prose commentary to 10 lines).

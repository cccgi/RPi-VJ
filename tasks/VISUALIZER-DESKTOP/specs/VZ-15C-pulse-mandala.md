# VZ-15C — Original preset: Pulse Mandala

## Goal

Author a waveform-driven mirrored polar mandala with bounded feedback.

## Existing files allowed

- Read one working preset/schema example selected by the orchestrator.
- Create `vj/shows/presets/pulse-mandala.toml`.

## Requirements

Use waveform domain, mirrored radial layout, 6–12 angular repeats, bar-phase rotation, onset flash, time-based feedback decay, violet/orange palette, and half-resolution bloom. Persistent state must reset on explicit reset and preset reload.

Observable: waveform shape changes with input rather than only volume; trails decay at similar real-time speed at 30/60/120 fps; silence fades to black.

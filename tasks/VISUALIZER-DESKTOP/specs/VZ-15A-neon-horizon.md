# VZ-15A — Original preset: Neon Horizon

## Goal

Author a mirrored spectrum-history surface with an original palette and light bloom.

## Existing files allowed

- Read one working preset/schema example selected by the orchestrator.
- Create `vj/shows/presets/neon-horizon.toml`.

## Requirements

Use 128 history rows, mirrored Cartesian layout, cyan/green/violet palette, slow bar-phase drift, bass-controlled height, treble-controlled edge brightness, 0.5-scale history pass, and one half-resolution bloom stage. Stay within eight passes and the fixed macro controls.

Observable on RTX 3090: a stable moving horizon with low frequencies visibly separated from high-frequency detail; no text, logos, or Boris preset names/art.
